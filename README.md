# FitZone

Site web simple  dédié au sport : exercices, actualités musculation et MMA (infos sur les combattants), alimenté par des API open source.

## Structure
- `index.html` : page principale
- `css/` : styles
- `js/` : code JavaScript découpé en modules 

## Lancer le projet
Le projet utilise des modules  : il ne fonctionne pas en double-clique simple:

    cd fitzone
    python -m http.server 5500

ou bien avec:

    npx serve .
